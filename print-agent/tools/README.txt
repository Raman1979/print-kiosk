Put SumatraPDF.exe (portable, 64-bit) here.

Download: https://www.sumatrapdfreader.org/download-free-pdf-viewer
Choose "64-bit Portable" (not the installer) and save the file in this
folder, renamed to exactly: SumatraPDF.exe

This is optional. Without it, PDF printing still works, but the paper
size and "both sides" options your customers choose will be ignored.
